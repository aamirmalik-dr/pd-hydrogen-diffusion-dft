# How the CP-PAW runs were set up

A practical record of the workflow, written so that the calculations in `calculations/` can be redone or extended. CP-PAW is documented at https://cppaw.org; the input syntax is `!BLOCK KEY=value ... !END`, nested, with `!EOB` closing the file.

## Files of one calculation

| File | Role |
|---|---|
| `name.strc` | structure: length unit, lattice, k-point density, species and augmentation setups, atoms, constraints |
| `name.cntl` | control: cutoff, functional, wave-function and atom dynamics, occupations |
| `name.prot` | protocol written by the code: settings echo, per-step trace, energy reports, final atom list with forces, timing |
| `name.rstrt` | restart file with wave functions and positions (binary, not committed) |
| `name.strc_out` | the actual structure at the end of the run, in machine-readable form |

## Two-stage minimisation

Metals need fractional occupations, so every run carries the Mermin block with the tetrahedron method. The wave functions are converged before the atoms are allowed to move:

1. `START=T`, only `!PSIDYN`: damped dynamics of the wave functions with the atoms frozen, until the automatic stop criterion.
2. `START=F` plus `!RDYN`: restart from the stage-1 restart file, propagate atoms and wave functions together with friction, until the forces are relaxed.

Both stages of every run are committed. Stage-2 protocols in this project contain two consecutive runs because the code appends to the protocol; the parsers use the last run.

## Bulk Pd and the supercell

Primitive fcc cell with lattice vectors (0, 1/2, 1/2), (1/2, 0, 1/2), (1/2, 1/2, 0) in units of a = 3.89 A and one atom at the origin. The 2 x 2 x 2 supercell uses the cubic lattice vectors scaled by 2 and the 32 positions generated by `pdhdiff.structure.supercell_pd_positions`, which reproduces the committed structure file atom for atom. Specifying `!KPOINTS R=20` instead of a grid keeps the k-point density comparable between the two cells (63 and 8 irreducible points).

Post-processing tools used on the primitive cell: `paw_dos.x` with `pd.dcntl` (total and s, p, d weights of atom PD1) and `paw_bands.x` with `pd.bcntl` (six straight lines through Gamma, X, W, L, Gamma, K, X, 8 bands). The resulting text files are committed and read by `pdhdiff.cppaw_io.parse_dos` and `parse_bands`.

## Hydrogen and the constrained path

The H atom is added as species `H_` with a fictitious mass `M=2.` (only for the Car-Parrinello dynamics; the real mass enters the attempt frequencies) at the octahedral position (0, 0, 1/2) or the tetrahedral position (1/4, 1/4, 3/4).

For the path, `scripts/build_path_inputs.py` takes the octahedral structure file, moves H to O + x (T - O) for x = 0.0, 0.1, ..., 1.0, and appends the translation-invariant linear constraint with `MOVE=F`, so the constraint is fixed at the value defined by the starting geometry. `SHOW=T` prints the constraint value and force in every energy report, which is how the reaction coordinate is verified after the fact. Each point ran the two stages above; small steps in x keep the Pd cage close to relaxed from one point to the next.

The value CP-PAW prints is the linear form evaluated on Cartesian positions in bohr, a (g - 2/3): -4.90 bohr at O and +2.45 bohr at T. `pdhdiff.structure.constraint_value_to_g` converts it back.

## Extending the study

Sensible next runs with the same inputs: `!KPOINTS R=30` and `R=40` to test the barrier against k-point density; a 3 x 3 x 3 cubic supercell (108 Pd) for the cell-size error; extra path points at x = 0.05, 0.95 and 1.05 to pin the curvatures; and the reverse path T to O started from the relaxed T structure as a consistency check of the constraint approach.
